# AR.T.L.A.S.
AR.T.L.A.S. orquesta los principales modelos de lenguaje — GPT, Claude, Gemini, Llama, DeepSeek y modelos locales — y elige el más adecuado para cada tarea. Chat, agentes, búsqueda web, analítica de datos y creación de contenido, todo en un mismo lugar y con tus propias claves.
Router inteligente: Analiza la intención de cada consulta y la envía al modelo óptimo: rápido, equilibrado, máxima calidad, razonamiento o económico. Si un modelo falla, el fallback reintenta solo con otro.
Consenso multimodelo: Consultá varios modelos a la vez y compará sus respuestas en paralelo, o dejá que AR.T.L.A.S. sintetice la mejor respuesta de consenso.
Búsqueda web con fuentes: Ante consultas de actualidad —o cuando un modelo no tiene el dato— busca en internet y responde citando las fuentes con enlaces.
Creación con IA: Sitios web, imágenes, presentaciones y código generados a partir de una descripción, con ayuda de la IA para mejorar tus prompts.
